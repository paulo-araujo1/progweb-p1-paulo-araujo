# Projeto 1 — Programação Web (UEPB · 2026.2)

**Aluno(a):** Paulo Cézar Silva de Araújo

**Disciplina:** Programação Web · Prof. Rodrigo Alves Costa

## Sobre

Aplicação fullstack (API Express em camadas + SQLite + frontend Bootstrap com Vanilla JS).

**Domínio:** Marketplace de aluguel de veículos. A modelagem está em [MODELAGEM.md](MODELAGEM.md).

## Estrutura

- `s1/` — exercícios da Semana 1: os quatro pilares da POO em JavaScript.
- `s2/` — exercícios da Semana 2: princípios SOLID e Modelagem inicial.
- `s3/` — Exercícios da Semana 3:

  - `banco-api/` — API bancária de demonstração em camadas (recurso `clientes`e `contas`).
  - `backend/` — API do Projeto 1 (**VemDeCar**, contendo as entidades **Anunciante** e **Veículo**) estruturada em camadas (Route → Controller → Service → Model) utilizando Node.js e Express 5.
